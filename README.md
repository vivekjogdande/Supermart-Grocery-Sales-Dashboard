# 🛒 Supermart Grocery Sales Dashboard

### 📊 Sales Data Analysis | Excel Dashboard | Business Intelligence

An end-to-end grocery sales analysis project built using **Microsoft Excel** to explore sales performance, compare product categories, evaluate outlet performance, and transform raw sales data into meaningful business insights through interactive visualizations and KPI metrics.

---

## 📌 Project Overview

The Supermart Grocery Sales Dashboard analyzes grocery sales data to understand sales patterns across product categories, outlet types, and outlet locations.

Using Excel formulas, PivotTables, PivotCharts, and statistical techniques, this project organizes raw data into a structured analysis and visual dashboard that helps users explore sales performance and identify potential business opportunities.

## 🎯 Project Objectives

- Analyze total, average, and median sales.
- Compare average sales across different product categories.
- Evaluate sales performance across outlet types.
- Analyze sales differences across outlet location types.
- Measure sales variation using standard deviation.
- Identify potential sales outliers using the Interquartile Range (IQR) method.
- Present key findings through charts and a dashboard layout.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Excel formulas and statistical functions
- PivotTables and PivotCharts
- Data cleaning and organization
- Data visualization
- Descriptive statistical analysis
- Interquartile Range (IQR) outlier detection

## 📈 Work Completed

### 1. Data Analysis and Preparation
- Worked with grocery sales data organized into product and outlet attributes.
- Used the Sales column for statistical calculations and comparisons.
- Created a visibility classification to group item visibility into Low, Medium, and High ranges.

### 2. Key Performance Indicators (KPIs)
Calculated key sales metrics, including:

- Total Sales
- Average Sales
- Median Sales
- Minimum Sales
- Maximum Sales
- Sales Variation (Standard Deviation)

### 3. Product Category Analysis
Prepared an analysis to compare average sales across product categories and identify the categories with relatively higher or lower average sales.

### 4. Outlet Type Analysis
Compared average sales across outlet types to evaluate differences in sales performance.

### 5. Outlet Location Analysis
Analyzed average sales by outlet location type to understand how sales differ across locations.

### 6. Sales Outlier Analysis
Applied the **Interquartile Range (IQR)** method:

- Calculated the first quartile (Q1).
- Calculated the third quartile (Q3).
- Calculated the IQR.
- Determined lower and upper outlier limits.
- Classified sales records as high sales outliers, low sales outliers, or normal.

### 7. Dashboard Development
Designed a dashboard layout to bring important sales metrics and visual comparisons together in one place.

Planned and selected dashboard components include:
- KPI summary cards
- Average sales by product category
- Average sales by outlet type
- Average sales by outlet location
- Total sales by outlet type

## 📊 Key Metrics

| Metric | Purpose |
|---|---|
| Total Sales | Measures overall sales value |
| Average Sales | Shows average sales per record |
| Median Sales | Shows the middle sales value |
| Minimum & Maximum Sales | Identifies the lowest and highest observed sales |
| Standard Deviation | Measures variation in sales |
| IQR Limits | Helps flag potentially unusual sales values |
